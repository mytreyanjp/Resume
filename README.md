# Resume Builder App

A React Native Expo app for building resumes with Google authentication and Firebase.

## Setup
1. Install dependencies:
   ```bash
   npm install
   ```
2. Configure Firebase:
   - Update `src/firebaseConfig.js` with your Firebase project values.
   - Add your Google OAuth client IDs in `src/screens/AuthScreen.js`.
3. Run the app:
   ```bash
   npm start
   ```

## What’s included
- Google Sign-In screen using Expo Auth Session
- Firebase Auth integration
- Placeholder for resume builder features
